# 갑옷 강화하기

5주 프로젝트용 위험·보상형 강화 시뮬레이션 웹게임입니다.

낡은 갑옷을 강화하고 판매하거나 재도전하면서, 여러 세션에 걸쳐 +15 전설의 갑옷 완성을 목표로 합니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 별도 빌드 과정은 필요하지 않습니다.

## 현재 구현

- +0~+15 갑옷 강화
- 강화 전 성공 확률 표시
- 성공·실패·파괴
- 방지권
- 갑옷 조각 획득 및 +3·+5·+7 복구
- 누적 투자금 기반 판매가
- 판매·파괴 후 새 +0 갑옷 재시작
- +15 전설의 대장장이 결과 화면
- 브라우저 자동 저장
- 익명 행동 로그 저장 및 JSON 내보내기
- PC·모바일 반응형 화면

초기 버전의 갑옷은 네모 도형으로 표시합니다.

## 데이터와 로그

게임 상태와 로그는 브라우저 `localStorage`에 저장됩니다. 게임 화면의 `로그 저장` 버튼으로 로그 JSON을 내보낼 수 있습니다. 파일명에는 내보낸 시각과 세션 ID가 포함되어 여러 사용자의 파일을 구분할 수 있습니다.

내보낸 개인 로그와 테스트 산출물은 저장소에 올리지 않도록 `.gitignore`에 등록되어 있습니다.

## 브라우저 테스트

Playwright 테스트를 실행하려면:

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

현재 자동화 테스트는 초기 강화, 저강화 판매, 파괴·복구, 저장 유지, +15 달성, 데이터 초기화를 확인합니다.
